# 🎮 Signal Hunter

Signal Hunter is a retro-themed browser game built using HTML, CSS, and JavaScript.

The game is presented as a signal-tracking mission where the player must locate a hidden transmission before running out of power or time. Instead of a traditional number guessing game, the gameplay is designed around a futuristic radar and scanning system with a retro arcade-inspired interface.

## 🚀 Features

* Retro arcade-inspired UI
* CRT screen effect
* Animated starfield background
* Difficulty levels (Easy, Medium, Deep Space)
* Radar-based signal proximity system
* Scan history tracking
* Timer and power management
* High score tracking using Local Storage
* Achievement system
* Responsive design for desktop and mobile

## 🛠️ Technologies Used

* HTML5
* CSS3
* JavaScript (ES6)
* Browser Local Storage

## 🎯 How to Play

1. Enter your commander name.
2. Select a difficulty level.
3. Enter coordinates and press Enter to scan.
4. Use signal feedback to move closer to the hidden target.
5. Locate the signal before power or time runs out.
